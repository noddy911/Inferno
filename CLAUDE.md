# my-project

A Node.js project scaffolded for Claude Code.

## Commands

- `npm start` — run the app (`node src/index.js`)
- `npm run dev` — run with watch mode (`node --watch`)
- `npm test` — run tests (`node --test`)

## Project structure

- `src/` — application source code
- `test/` — tests (run with `node --test`)

## Conventions

- ESM (`"type": "module"`) — use `import`/`export`, not `require`
- Plain Node.js, no framework or build step yet
- Keep files small and focused; match existing style in the file you're editing
